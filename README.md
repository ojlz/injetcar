# MotorFix — Oficina Mecânica (projeto fictício)

> **Aviso:** site 100% fictício criado para portfólio. Nome, endereço
> (Av. Central Fictícia, 264 — Porto Fictício/EX), telefone
> `(00) 90000-0004`, WhatsApp e mapas são inventados. Nenhum dado é real
> e não representa nenhuma empresa.

🌐 **Demo no ar:** https://motorfix-ex.vercel.app

Landing page de uma oficina mecânica fictícia: câmbio automático,
arrefecimento, revisão completa, injeção eletrônica, catálogo de serviços
com orçamento via WhatsApp e rotas no mapa.

## Stack

- HTML + CSS + JS puros (sem build)
- SEO: meta tags, Open Graph, JSON-LD, `sitemap.xml`, `robots.txt`

## Estrutura

| Arquivo            | O quê           |
| ------------------ | --------------- |
| `index.html`       | Página completa |
| `styles.css`       | Estilos         |
| `app.js`           | Interações      |
| `injet.png`        | Imagem da capa  |
| `site.webmanifest` | PWA básico      |
